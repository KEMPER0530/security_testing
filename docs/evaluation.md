# 評価ルール 2026-11-01.2

## 診断後に問題を評価
所有確認とシステム重要度の事前入力は廃止。URL登録後に診断を開始できる。
公開1ページの観測結果から、検出した問題を暫定深刻度（高・中・低）で表示する。
これは独自の設定評価で、CVSSスコア・業務影響・システム重要度の推定ではない。
悪用可能性は未確認。深刻度・対応優先度はルール版とともにレポートへ保存する。

| 検出した設定 | 暫定深刻度 | 対応優先度 |
|---|---|---|
| HTTPS不使用、TLS不備、Mixed Content、HTTP→HTTPS誘導なし | 高 | P1 · 優先対応 |
| CSP、HSTS、埋込制御、Cookie属性の不備 | 中 | P2 · 計画対応 |
| MIME型保護の不備、識別ヘッダー公開 | 低 | P3 · 改善推奨 |

問題を検出した所見を深刻度順に表示し、未検出・未実施・対象外は後ろに表示する。
未検出のみ「対応不要」。未実施・対象外・確認不能は「未評価／要確認」で、安全とは判定しない。
TLS接続に失敗した場合は現在の取得処理では診断失敗となり、証明書検証を無効化しない。

## CVSS
未評価はnullで、0.0とは別。公開設定のうち評価条件を定義した項目は、追加条件を明記してCVSS v4.0の参考評価を計算する。
Inspectorの既知脆弱性は提供元のCVSS・バージョン・ベクトルを保持し、数値の整合性を検証する。設定観測だけで具体的な悪用条件を確定できない追加チェックは適用外と理由を示す。
独自の暫定深刻度からCVSSスコアを生成しない。
https://www.first.org/cvss/v4.0/specification-document

## 診断範囲
TLS（標準TLS検証）、HTTPS利用、CSPのscript/default制約、HSTS、nosniff、埋込制御、Cookie属性、静的Mixed Content、識別ヘッダーを確認。
CSPは完全なポリシーパーサーではない。同一ルール版・対象・検査範囲のみ比較可能。
JS実行後、外部CSS、認証後ページ、業務ロジック、内部構成は対象外。
